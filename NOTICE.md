# Adaptive Smart Manager — attribution

Adaptive Smart Manager combines and modifies the Smart Thread Manager and
Smart GPU Manager code originally published by kuuk / Omisse in `ul-stmmod`.

Original project: https://github.com/Omisse/ul-stmmod
Original license: MIT

The original player-facing concepts and distribution modes are preserved:
Ratio, Demand, Graph, chaining, and the count/count-per-second toggle.

Adaptive Smart Manager adds a shared implementation, defensive bug fixes,
cleaner registration/version handling, and a read-only compatibility surface
for Adaptive Auto Connector.
